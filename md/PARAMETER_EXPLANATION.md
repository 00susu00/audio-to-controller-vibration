# 🎛️ 平滑因子与频率分离点详解

## 📖 参数含义

### 🌊 平滑因子 (Smoothing Factor)

**定义**：控制震动强度变化的平滑程度，范围0-1

**作用原理**：
```python
# 指数平滑算法
new_intensity = old_intensity * smoothing + current_intensity * (1 - smoothing)
```

**数值含义**：
- **0.0**：无平滑，震动立即跟随音频变化（最敏锐）
- **0.5**：中等平滑，平衡响应速度和稳定性
- **1.0**：最大平滑，震动变化非常缓慢（最稳定）

**实际效果**：
```
音频: 安静 → 突然大声
├── 平滑因子 0.1：震动立即从弱变强 ⚡
├── 平滑因子 0.5：震动逐渐从弱变强 📈
└── 平滑因子 0.9：震动缓慢从弱变强 🐌
```

### 🎵 频率分离点 (Frequency Cutoff)

**定义**：分离低频和高频信号的临界频率，单位Hz，范围100-1000

**作用原理**：
```python
# 低通滤波器：保留低于分离点的频率
low_freq_signal = 低通滤波(音频, 分离点)

# 高通滤波器：保留高于分离点的频率  
high_freq_signal = 高通滤波(音频, 分离点)
```

**数值含义**：
- **100Hz**：只有很深的低音算"低频"，大部分声音归为"高频"
- **300Hz**：平衡分离，人声、乐器合理分配
- **1000Hz**：较多声音归为"低频"，只有尖锐声归为"高频"

**实际效果**：
```
测试信号：150Hz低音 + 600Hz中音

分离点 200Hz：
├── 低频信号：主要是150Hz成分 🔉
└── 高频信号：主要是600Hz成分 🔊

分离点 500Hz：  
├── 低频信号：包含150Hz + 600Hz 🔊
└── 高频信号：很少内容 🔈
```

## 🔧 平滑因子问题分析

### 🔍 问题原因
通过代码分析发现，平滑算法可能在特定情况下不生效：

1. **性能模式**：在高性能需求时，平滑可能被简化
2. **时间因子**：标准模式中使用时间补偿，可能影响效果
3. **初始化问题**：`current_left_intensity`和`current_right_intensity`可能未正确初始化

### 🛠️ 修复方案

#### 方案1：检查平滑因子设置
```python
# 在VibrationMapper中
if self.smoothing_factor <= 0.05:
    # 完全无平滑或最小平滑
    return left_intensity, right_intensity
```

#### 方案2：优化时间补偿
```python
# 避免时间补偿过度影响平滑效果
actual_smoothing = self.smoothing_factor  # 直接使用设置值
```
