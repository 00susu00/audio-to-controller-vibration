# 声音转手柄震动控制器

一个将音频信号实时转换为手柄震动反馈的Python程序，支持丰富的参数配置和直观的GUI界面。

## 功能特点

- 🎵 **实时音频处理**: 支持多种音频输入设备，实时采集和分析音频信号
- 🎮 **XInput兼容**: 支持Xbox系列手柄和其他XInput兼容设备
- 🔧 **智能频率分离**: 自动将低频音频映射到左马达，高频音频映射到右马达
- ⚙️ **丰富参数配置**: 提供众多可调节参数，满足不同使用需求
- 🎨 **直观GUI界面**: 实时监控音频和震动状态，方便参数调节
- 📊 **实时图表显示**: 音频频谱和震动强度的实时可视化
- 🔄 **多种预设模式**: 内置均衡、重低音、高音、柔和、强烈等预设
- 💾 **配置保存加载**: 支持配置文件的保存和加载

## 系统要求

- Windows 10/11 (推荐)
- Python 3.7+
- XInput兼容手柄（Xbox 360/One/Series X|S）
- 音频输入设备（麦克风、线路输入等）

## 安装依赖

```bash\n# 克隆或下载项目文件\n# 安装Python依赖包\npip install -r requirements.txt\n```\n\n### 主要依赖包\n\n- `XInput-Python`: XInput手柄控制\n- `pyaudio`: 音频输入处理\n- `numpy`: 数值计算\n- `scipy`: 信号处理和滤波\n- `matplotlib`: 图表显示\n- `tkinter`: GUI界面（通常随Python安装）\n\n## 使用方法\n\n### 1. 图形界面模式（推荐）\n\n```bash\npython main.py\n```\n\n启动后会打开GUI界面，提供以下功能：\n- 音频设备选择和配置\n- 实时参数调节\n- 音频和震动状态监控\n- 预设配置选择\n- 配置文件管理\n\n### 2. 命令行模式\n\n```bash\n# 基础用法\npython main.py --no-gui\n\n# 指定预设和参数\npython main.py --no-gui --preset bass_heavy --sample-rate 48000\n\n# 详细输出模式\npython main.py --no-gui --verbose\n```\n\n### 3. 设备测试\n\n```bash\n# 列出音频设备\npython main.py --list-devices\n\n# 测试音频输入\npython main.py --test-audio\n\n# 测试手柄震动\npython main.py --test-controller\n```\n\n## 参数配置说明\n\n### 基础参数\n\n- **整体强度** (0.0-2.0): 控制整体震动强度倍数\n- **低频敏感度** (0.0-3.0): 低频音频的敏感度，影响左马达\n- **高频敏感度** (0.0-3.0): 高频音频的敏感度，影响右马达\n- **平滑度** (0.0-1.0): 震动变化的平滑程度，越大越平滑\n\n### 高级参数\n\n- **频率分离点** (100-1000Hz): 区分低频和高频的分界点\n- **最小音量阈值** (0.0-0.1): 触发震动的最小音量\n- **最大音量阈值** (0.1-2.0): 震动饱和的音量上限\n- **攻击时间** (0.01-1.0秒): 震动强度上升的速度\n- **衰减时间** (0.1-3.0秒): 震动强度下降的速度\n\n### 预设模式\n\n1. **均衡模式** (balanced): 低频和高频平衡，适合大多数音乐\n2. **重低音模式** (bass_heavy): 增强低频响应，适合电子音乐\n3. **高音模式** (treble_heavy): 增强高频响应，适合人声\n4. **柔和模式** (gentle): 降低整体强度，更柔和的震动\n5. **强烈模式** (intense): 增强响应速度和强度，适合游戏\n\n## GUI界面说明\n\n### 左侧控制面板\n\n- **设备设置**: 音频设备选择和控制器信息\n- **控制按钮**: 开始/停止转换、紧急停止、震动测试\n- **预设配置**: 快速选择和应用预设模式\n- **参数调节**: 实时调节各项参数的滑块\n- **配置管理**: 保存、加载、重置配置\n\n### 右侧监控面板\n\n- **实时数据**: 显示当前音频音量和马达强度数值\n- **音频频谱图**: 实时显示低频和高频音量变化\n- **震动强度图**: 实时显示左右马达的震动强度\n\n### 状态栏\n\n- **状态信息**: 显示当前程序运行状态\n- **FPS指示**: 显示音频处理帧率\n\n## 配置文件\n\n程序会自动保存配置到 `audio_vibration_config.json` 文件，包含：\n\n```json\n{\n  \"vibration_mapper_params\": {\n    \"overall_intensity\": 0.8,\n    \"low_freq_sensitivity\": 1.0,\n    \"high_freq_sensitivity\": 1.0,\n    \"smoothing_factor\": 0.7,\n    \"frequency_cutoff\": 300,\n    \"min_volume_threshold\": 0.01,\n    \"max_volume_threshold\": 1.0,\n    \"attack_time\": 0.1,\n    \"decay_time\": 0.5\n  },\n  \"audio_processor_params\": {\n    \"sample_rate\": 44100,\n    \"chunk_size\": 4096,\n    \"device_index\": null\n  },\n  \"gui_params\": {\n    \"preset\": \"balanced\"\n  }\n}\n```\n\n## 命令行参数\n\n```\npython main.py [选项]\n\n选项:\n  --no-gui              不启动GUI界面（命令行模式）\n  --config CONFIG       配置文件路径\n  --sample-rate RATE    音频采样率（默认44100）\n  --chunk-size SIZE     音频块大小（默认4096）\n  --device-id ID        音频设备ID\n  --preset PRESET       预设配置（balanced/bass_heavy/treble_heavy/gentle/intense）\n  --test-audio          测试音频输入设备\n  --test-controller     测试手柄震动功能\n  --list-devices        列出可用的音频输入设备\n  --verbose, -v         详细输出模式\n  --help, -h            显示帮助信息\n```\n\n## 使用技巧\n\n1. **首次使用**: 建议先运行设备测试，确保音频输入和手柄震动都正常工作\n2. **参数调节**: 从预设模式开始，再根据个人喜好微调参数\n3. **音频质量**: 建议在安静环境中使用，避免背景噪音影响效果\n4. **手柄兼容**: 确保手柄驱动程序已正确安装，建议使用官方驱动\n5. **性能优化**: 如果出现延迟，可以适当降低音频采样率或增大块大小\n\n## 故障排除\n\n### 常见问题\n\n1. **无法检测到手柄**\n   - 检查手柄连接\n   - 确认手柄驱动已安装\n   - 尝试重新连接手柄\n\n2. **音频输入无响应**\n   - 检查麦克风权限设置\n   - 尝试不同的音频设备\n   - 调整系统音频输入音量\n\n3. **震动效果不理想**\n   - 调整频率分离点\n   - 修改敏感度参数\n   - 尝试不同的预设模式\n\n4. **程序运行缓慢**\n   - 降低音频采样率\n   - 增大音频块大小\n   - 关闭不必要的后台程序\n\n### 错误日志\n\n程序会在控制台输出详细的错误信息，遇到问题时请查看控制台输出。使用 `--verbose` 参数可以获得更详细的调试信息。\n\n## 技术原理\n\n### 音频处理流程\n\n1. **音频采集**: 使用PyAudio实时采集音频数据\n2. **频谱分析**: 通过FFT变换分析音频频谱\n3. **频率分离**: 使用数字滤波器分离低频和高频信号\n4. **音量计算**: 计算RMS音量和峰值音量\n5. **平滑处理**: 应用移动平均和指数平滑\n\n### 震动映射算法\n\n1. **音量标准化**: 将音频音量映射到0-1范围\n2. **敏感度调整**: 应用用户设定的敏感度参数\n3. **动态范围压缩**: 增强小音量的响应性\n4. **攻击衰减**: 模拟自然的震动响应曲线\n5. **马达控制**: 转换为XInput格式并发送到手柄\n\n## 开源协议\n\n本项目采用MIT开源协议，详见LICENSE文件。\n\n##
