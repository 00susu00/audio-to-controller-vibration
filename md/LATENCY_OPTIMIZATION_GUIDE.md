# 🚀 延迟优化指南

## 📊 延迟来源分析

### 1. **音频处理延迟**
```
总延迟 = 音频块延迟 + 队列缓冲延迟 + 处理延迟 + 系统延迟
```

- **音频块延迟**: `chunk_size / sample_rate * 1000` (ms)
- **队列缓冲延迟**: `queue_size * chunk_delay`
- **处理延迟**: 频谱分析、滤波处理 (~1-3ms)
- **系统延迟**: 操作系统调度、驱动延迟 (~2-10ms)

### 2. **当前默认配置延迟**
```
chunk_size = 32
sample_rate = 44100Hz
queue_size = 3

音频块延迟 = 32/44100 * 1000 = 0.73ms
队列延迟 = 3 * 0.73 = 2.18ms  
估算总延迟 ≈ 5-8ms (良好水平)
```

## 🔧 优化方法

### 方法1: 调整音频块大小 ⭐⭐⭐⭐⭐
**最有效的优化方法**

```bash
# 极致延迟 (需要高性能系统)
python main.py --chunk-size 16    # ~0.36ms + 缓冲 ≈ 2-3ms

# 超低延迟 (推荐)
python main.py --chunk-size 32    # ~0.73ms + 缓冲 ≈ 4-6ms (当前默认)

# 低延迟
python main.py --chunk-size 64    # ~1.45ms + 缓冲 ≈ 6-10ms

# 平衡模式  
python main.py --chunk-size 128   # ~2.9ms + 缓冲 ≈ 10-15ms
```

**注意**：chunk_size越小，CPU占用越高，可能导致音频断断续续

### 方法2: 优化振动映射参数 ⭐⭐⭐⭐
**减少处理复杂度**

```bash
# 使用最快响应预设
python main.py --preset intense

# 或在GUI中手动设置：
# - 平滑因子: 0.0 (无平滑)
# - 攻击时间: 0.01s (快速响应)  
# - 衰减时间: 0.1s (快速衰减)
```

### 方法3: 关闭高级功能 ⭐⭐⭐
**在GUI中禁用以下功能**：
- ❌ 声音识别 (节省 ~2-5ms)
- ❌ 冲击增强 (节省 ~1-3ms)
- ❌ 频谱质心分析
- ❌ 6频段分析

### 方法4: 设置高进程优先级 ⭐⭐⭐
```bash
python main.py --high-priority --chunk-size 32
```

### 方法5: 音频设备优化 ⭐⭐⭐⭐
**Windows音频设置**：
1. 右键扬声器图标 → 声音
2. 播放/录制 → 属性 → 高级
3. 设置为 16位 44100Hz (CD音质)
4. ✅ 启用独占模式
5. ❌ 禁用所有音效增强

### 方法6: 系统级优化 ⭐⭐⭐
**Windows优化**：
```bash
# 1. 设置高性能电源计划
powercfg -setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c

# 2. 关闭不必要的后台程序
# 3. 设置实时优先级 (需要管理员权限)
```

### 方法7: 硬件建议 ⭐⭐⭐⭐
**推荐配置**：
- **CPU**: 4核心3.0GHz+ (单核性能重要)
- **内存**: 8GB+ DDR4
- **音频**: 板载音频或低延迟USB接口
- **存储**: SSD (减少系统IO延迟)

## 🛠️ 故障排除

### 问题1: 音频断断续续
**原因**: chunk_size过小，CPU无法及时处理
**解决**: 
```bash
# 增大chunk_size
python main.py --chunk-size 64

# 或关闭其他程序，释放CPU
```

### 问题2: 震动延迟明显
**原因**: 系统音频驱动延迟高
**解决**:
1. 更新音频驱动
2. 使用ASIO驱动 (专业音频接口)
3. 启用音频独占模式

### 问题3: CPU占用过高
**原因**: chunk_size过小 + 高级功能全开
**解决**:
```bash
# 平衡配置
python main.py --chunk-size 32 --preset balanced

# 在GUI中关闭声音识别
```

## 🎯 总结

**最优延迟优化策略**:
1. **首选**: 降低chunk_size (32 → 16)
2. **其次**: 设置高优先级 + intense预设
3. **辅助**: 关闭不需要的高级功能
4. **系统**: 优化音频驱动和系统设置
5. **硬件**: 使用高性能硬件和专业音频接口

通过合理的配置组合，可以将总延迟控制在 **2-6ms** 范围内，达到准专业级的响应速度！🚀
