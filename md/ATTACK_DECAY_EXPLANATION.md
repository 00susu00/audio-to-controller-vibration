# 🎛️ Attack Time 与 Decay Time 参数详解

## 📖 参数含义

### ⚡ **Attack Time (攻击时间)**
**定义**：震动强度从当前值上升到目标值所需的时间（秒）

**作用机制**：
```python
# 当目标强度 > 当前强度时（音频变大声）
rate = 1.0 / attack_time
change = min(target - current, rate × time_delta)
new_intensity = current + change
```

**实际效果**：
- **数值越小** → 震动响应越快，上升越急剧 ⚡
- **数值越大** → 震动响应越慢，上升越平缓 🐌

### 📉 **Decay Time (衰减时间)**  
**定义**：震动强度从当前值下降到目标值所需的时间（秒）

**作用机制**：
```python
# 当目标强度 < 当前强度时（音频变小声）
rate = 1.0 / decay_time  
change = min(current - target, rate × time_delta)
new_intensity = current - change
```

**实际效果**：
- **数值越小** → 震动衰减越快，下降越急剧 📉
- **数值越大** → 震动衰减越慢，下降越平缓 📈

### 🔍 数值解析

#### 标准模式 (0.1秒, 0.5秒)
```
Attack Time = 0.1秒:
- 震动从0%上升到100%需要0.1秒
- 适中的响应速度，避免过于突兀

Decay Time = 0.5秒:  
- 震动从100%下降到0%需要0.5秒
- 较长的余韵，震动缓慢消失
- 营造更自然的震动体验
```

## 🔧 技术实现原理

### ⚙️ **计算公式**
```python
def calculate_attack_decay(target, current, time_delta):
    if target > current:
        # 攻击阶段：快速上升
        rate = 1.0 / attack_time
        change = min(target - current, rate * time_delta)
        return current + change
    else:
        # 衰减阶段：缓慢下降  
        rate = 1.0 / decay_time
        change = min(current - target, rate * time_delta)
        return current - change
```

### 📈 **变化曲线**

#### Attack Phase (上升阶段)
```
震动强度
    ^
    |     目标强度 ----
    |    /
    |   /  <- Attack Time控制这个斜率
    |  /
    | /
    |/___________________> 时间
   当前强度

斜率 = 1 / Attack Time
- Attack Time越小，斜率越陡，上升越快
- Attack Time越大，斜率越缓，上升越慢
```

#### Decay Phase (衰减阶段)  
```
震动强度
    ^
    |
    |\
    | \  <- Decay Time控制这个斜率
    |  \
    |   \
    |    \_______________> 时间
    |     目标强度

斜率 = -1 / Decay Time  
- Decay Time越小，斜率越陡，下降越快
- Decay Time越大，斜率越缓，下降越慢
```
