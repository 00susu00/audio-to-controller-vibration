# 🎚️ 频率差增强功能指南

## 🚀 新功能：频率差增强

现在您可以使用全新的"频率差"参数来增强震动的对比度和差异感！

### 🎯 功能原理

**频率差**参数可以：
- 自动识别哪个频段（低频/高频）占主导地位
- 增强主导频段的震动强度
- 同时减弱非主导频段的震动强度
- 让震动效果更加突出和有层次感

### 📊 参数说明

| 参数值 | 效果描述 | 应用场景 |
|--------|----------|----------|
| **0.0** | 无变化，保持原始震动比例 | 平衡的音乐体验 |
| **0.3** | 轻微增强主导频段，适度弱化非主导频段 | 日常游戏使用 |
| **0.6** | 明显增强主导频段，显著弱化非主导频段 | 竞技游戏，需要清晰区分 |
| **1.0** | 最大对比度：主导频段 = 原主导 + 原非主导，非主导频段 = 0 | 极端差异化体验 |

### 🧮 计算公式

当参数值为 `factor` 时：
- **主导频段** = 原主导强度 + (原非主导强度 × factor)
- **非主导频段** = 原非主导强度 × (1 - factor)

### 🎮 实际应用场景

#### FPS游戏 - 推荐值：0.6-0.8
```
爆炸声：低频主导
├── 原本：左马达 0.7，右马达 0.3
├── factor = 0.7
└── 结果：左马达 0.91，右马达 0.09
    → 爆炸感更加震撼，减少高频干扰
```

#### 金属碰撞 - 推荐值：0.5-0.7
```
刀剑声：高频主导
├── 原本：左马达 0.2，右马达 0.8
├── factor = 0.6  
└── 结果：左马达 0.08，右马达 0.92
    → 金属撞击感更加尖锐清晰
```

#### 音乐欣赏 - 推荐值：0.2-0.4
```
鼓点：低频主导
├── 原本：左马达 0.6，右马达 0.4
├── factor = 0.3
└── 结果：左马达 0.72，右马达 0.28
    → 鼓点更突出，但保持和谐
```

### ⚙️ 在GUI中使用

1. 打开程序：`python main.py`
2. 切换到 **"⚙️ 高级设置"** 选项卡
3. 找到 **"🎚️ 频率差增强"** 区域
4. 拖动 **"频率差"** 滑块：
   - 左侧（0.0）：无增强
   - 右侧（1.0）：最大差异
5. 实时感受震动变化

### 💡 调节技巧

#### 寻找最佳值
1. **从0.0开始**：感受原始震动
2. **逐步增加到0.3**：观察是否有改善
3. **继续调到0.6**：检查是否过于极端
4. **微调到最舒适的值**

#### 不同游戏类型的建议

| 游戏类型 | 推荐范围 | 说明 |
|---------|----------|------|
| **射击游戏** | 0.5 - 0.8 | 需要清晰区分爆炸和枪声 |
| **格斗游戏** | 0.4 - 0.7 | 突出打击感的差异 |
| **赛车游戏** | 0.3 - 0.5 | 区分引擎轰鸣和轮胎摩擦 |
| **音乐游戏** | 0.2 - 0.4 | 保持节拍感，不过度突出 |
| **恐怖游戏** | 0.6 - 0.9 | 增强恐怖氛围的对比 |

### 🔧 与其他参数的配合

#### 配合声音识别
- 频率差 + 声音识别 = 更精准的差异化
- 爆炸声会被智能识别并自动增强低频
- 再通过频率差进一步突出对比

#### 配合冲击增强
- 频率差 + 冲击增强 = 层次丰富的震动
- 冲击时刻会有瞬间强化
- 频率差确保强化的方向正确

#### 配合整体强度
- 先用整体强度调节总震动强度
- 再用频率差调节震动对比度
- 获得理想的震动体验

### 📋 配置保存

频率差参数会自动保存在配置文件中：

```json
{
  "advanced_settings": {
    "frequency_difference_factor": 0.6
  }
}
```

### ⚠️ 注意事项

1. **过高的数值**（0.8+）可能导致：
   - 震动过于单一
   - 失去层次感
   - 手柄过热

2. **高性能需求**下：
   - 频率差仍然有效
   - 但可能需要关闭声音识别
   - 依然能提供基础的差异化

3. **配合使用建议**：
   - 新用户先从0.3开始尝试
   - 有经验用户可直接调到0.5-0.6
   - 根据个人喜好和游戏类型调整
